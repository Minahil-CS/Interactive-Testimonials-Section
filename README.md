# 💬 Interactive Testimonials Section

>  A responsive and interactive testimonials section built using HTML, CSS, and JavaScript to showcase customer feedback in an attractive card-based layout.

---

## ✨ Features

- **📱 Fully Responsive:** Adaptive layout seamlessly scaling across desktop, tablet, and mobile screens.
- **🎛️ Interactive Filters:** Filter testimonials by role/category (Developers, Designers, PMs, Founders) or star rating.
- **🎠 Dual View Modes:** Toggle between a **Grid View** and a **Carousel View** with smooth slide transitions.
- **⭐ Star Ratings & Avatars:** Clean card layout highlighting user avatars, job titles, feedback text, and visual star ratings.
- **⚡ Dynamic Rendering:** Pure vanilla JavaScript implementation with no external framework dependencies.
